# Power BI Retail Sales Dashboard

This folder contains documentation for the Power BI dashboard developed for the Retail Sales Analysis project.

## Dashboard objectives
- Monitor total sales revenue.
- Compare revenue across months.
- Identify the highest-revenue products.
- Compare revenue by product category.
- Enable interactive filtering by month, product, and category.

## Tools
- Power BI
- DAX
- SQL (MySQL)

## Dataset
A fictional retail dataset containing 12 sales transactions from January to March 2026.

## Key findings
- Total revenue: R42,300
- Highest-revenue product: Laptop (R25,500)
- Highest-revenue month: February (R15,450)
- Leading category: Electronics (R29,750)

## Notes
This is a learning portfolio project using fictional data. The findings are illustrative and should not be interpreted as actual business results.

Dashboard screenshots and the Power BI report file will be added when available.
